Photogram — SPA социальная сеть для обмена фотографиями.
Стек: Vue 3, TypeScript, SCSS, Nest.js, MongoDB, Mongoose, Multer, Sharp.

Backend (Nest.js, MongoDB):
- Разработал RESTful API с архитектурой контроллер-сервис-репозиторий для работы с сущностями пользователей, постов и комментариев.
- Реализовал полноценные CRUD-операции, включая регистрацию, аутентификацию через JWT, создание/редактирование/удаление постов.
- Построил конвейер обработки загружаемых изображений: от приёма файла через Multer до оптимизации с использованием библиотеки Sharp (сжатие, изменение размеров, конвертация форматов) с целью снижения нагрузки на хранилище и ускорения загрузки для пользователей.
- Организовал хранение метаданных в MongoDB через Mongoose, настроил индексацию для ускорения запросов.

Frontend (Vue 3, TypeScript, SCSS):
- Разработал одностраничное приложение с модульной структурой, использованием Composition API и TypeScript для типизации данных.
- Реализовал главную ленту с карточками постов, каждая из которых содержит изображение, описание, автора, геолокацию и дату публикации.
- Создал адаптивный интерфейс с применением SCSS для кастомизации стилей, включая мобильную вёрстку.
- Добавил форму загрузки поста с возможностью выбора файла, интерактивным предпросмотром изображения до отправки, валидацией полей и индикацией процесса загрузки.

Ключевые особенности:
- Полноценный fullstack-цикл разработки: от проектирования API до реализации UI.
- Оптимизация работы с медиафайлами на серверной стороне, снижающая расход трафика и повышающая производительность.
- Пользовательский интерфейс с акцентом на удобство: предпросмотр фотографий, адаптивность, интуитивная навигация.

Запуск проекта:
Перед запуском убедитесь, что на вашем компьютере установлены Node.js и запущен локальный сервер MongoDB.

Запустите MongoDB (если ещё не запущен через графический интерфейс):
mongod --dbpath "C:/data/db"
Примечание: Убедитесь, что указанный путь C:/data/db существует, или измените команду на актуальный путь к вашей базе данных.

Установите зависимости и запустите серверную часть (Backend):
cd backend/
npm install
npm run start:dev

Установите зависимости и запустите клиентскую часть (Frontend):
cd frontend/
npm install
npm run dev
